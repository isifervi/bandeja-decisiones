# Bandeja de decisiones · plantilla

Página de una mini app de Telegram de ConsultorIA Isifervi. **Es una plantilla vacía:** las
tarjetas llegan comprimidas detrás del «#» de la dirección que abre el bot, y esa parte nunca
se envía al servidor. Aquí no hay ningún dato.

Se publica desde `Proyectos/meta-sistema-isifervi/bandeja-decisiones/web/` con `publicar_pages.py`.
